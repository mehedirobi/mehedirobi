## Featured Projects

### Khelaro — Turf Booking Platform

A full-stack turf booking platform designed to help users discover and book sports turfs in Dhaka.

**Features:** Turf discovery · Availability checking · Booking management · User & owner workflows

**Stack:** `React` `Tailwind CSS` `Node.js` `Express.js` `MongoDB`

[Client Repository](https://github.com/mehedirobi/khelaro-client) · [Server Repository](https://github.com/mehedirobi/khelaro-server)

### UrbanFix — Civic Issue Reporting Platform

A role-based civic issue reporting platform for submitting, managing, and tracking community issues.

**Features:** Authentication · Role-based dashboards · Issue management · REST API

**Stack:** `React` `Tailwind CSS` `Node.js` `Express.js` `MongoDB` `Firebase`
